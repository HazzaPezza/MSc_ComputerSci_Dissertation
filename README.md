# University of Liverpool MSc Final Year Dissertation Project
This page serves to showcase my final year dissertation project where I experimented using Convolutional Neural Networks to classify and understand SMS text datasets. This was designed in the context of digital forensics but ultimately solves a popular text classification problem - Spam / Ham detection in online communications. 

In the code here you will see that I prepared and coded in a CNN model to try and tackle this problem and you can find more of the issues with my work and what came out of it within teh dissertation file which I will include after I have graduated on the 09/12/25. I received a distinction grade for my Master's degree and I am happy to share this work with the world. 

## Code Re-Use / Copying
This work was done purely for research / education purposes so feel free to reuse the work as you see fit. I'm sure there are people out there that can make the model much more efficient than I and I welcome any and all feedback good or bad. Ultimately I'm not arrogant enough to claim that this code isn't improvable because it definately is and I understood that with the amount of work I took on that year.

## Installation and Use of the Model
It's worth noting if you try to use the model. You have to make sure your environment contains all of the libraries I used here. I realised far too late after submission that containerisation would have been best here as when I tried to get this model to work on my MacBook Pro it didn't seem to work. The code here has been run entirely on windows so I cannot guarantee that it would work on a Mac in its current form. That could have been to do with discrepencies in installations of the tech though. I just was too focused on dissertation deadlines to look into it any more than that and just decided to stick with it on my PC.

Installation:
  If you don't have all the modules installed. It won't run.
  Open the Jupyter Notebook and run each node sequentially - running out of order can lead to elements not being loaded into memory correctly.

That's it. Enjoy.
